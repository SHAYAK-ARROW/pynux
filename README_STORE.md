# Pynux Arrow (Lite) 🚀
**The Intelligent Python IDE for Mobile Developers**

Pynux Arrow Lite is a professional-grade, offline Integrated Development Environment (IDE) that allows users to write and execute Python code directly on their Android devices. Designed with a focus on education and hardware interaction, it provides a safe and powerful playground for learning modern programming.

## ✨ Key Features

- **Advanced Code Editor:** Feature-rich editor with syntax highlighting, auto-suggestion, and auto-save.
- **Native Bridge Integration:** Easily interact with device sensors, GPS, Bluetooth, and Wi-Fi using simple Python commands.
- **System Monitor:** Real-time diagnostics for CPU, RAM, and Battery health (Voltage, Current, and Capacity).
- **USB OTG Support:** Industry-standard serial communication support for external hardware prototyping.
- **Material 3 Design:** A modern, clean, and responsive user interface for a premium coding experience.

## 🛠️ Getting Started

Pynux Arrow Lite is ready to go out of the box. No internet connection is required to run your scripts or interact with hardware.

```python
import bridge

# Check your battery health
print(bridge.device.battery())

# Read ambient light sensor
print(bridge.sensors.get_light())
```

## 🔒 Privacy Committed

- **Offline-First:** All code execution happens locally.
- **No Data Collection:** We do not track, store, or share any user information.
- **Permission Transparency:** Permissions are only requested when explicitly called by your code.
